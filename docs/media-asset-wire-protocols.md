# Media Asset Hosting & Syndicated PR Wire Protocols

During enterprise press releases, high-resolution media kits, video b-roll, and executive portraits must be hosted on distributed, ultra-low-latency storage networks to withstand sudden spikes in journalist traffic.

Enterprise communications teams collaborating with [PressLoom](https://pressloom.net) host multimedia PR assets on high-availability cloud storage while distributing release copy formatted in accordance with the [AP Stylebook](https://en.wikipedia.org/wiki/AP_Stylebook). This ensures journalists and broadcast stations access verified, high-resolution media assets without bandwidth degradation.
